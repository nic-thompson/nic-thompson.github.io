# Portfolio Site — Nicolas Thompson

This repository contains the source for my personal portfolio website:

👉 https://nicolas-thompson.com

The site highlights my work as an ML Platform Engineer building event-driven telemetry pipelines, structured data infrastructure, and inference-ready backend systems on AWS.

---

## Overview

The portfolio presents representative platform engineering work across:

- telemetry ingestion pipelines
- structured event processing systems
- serverless AWS data infrastructure
- inference-ready backend architectures
- distributed observability tooling

It is designed as a concise technical profile for ML platform, data infrastructure, and backend engineering roles.

---

## Site Structure

Sections include:

- Engineering Impact
- Representative Systems
- Event-Driven ML Data Architecture
- Selected Open Source Projects

Content is aligned with production experience building analytics and ML-ready infrastructure platforms.

## Technology

The site is intentionally lightweight:

- semantic HTML
- modern CSS
- minimal JavaScript
- GitHub API integration for repository listing

No frontend framework is used to keep deployment simple and portable.
